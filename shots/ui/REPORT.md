## 多人实时同房验证

两个独立浏览器会话（隔离 cookie）进入同一房间：

1. 小李发「大家好，我是小李，这个需求我来跟进」→ 小王视角 4s 内轮询可见，气泡带「小李」归属
2. 小王回「好的小李，就交给你了」→ 小李视角可见，归属「小王」
3. 助手回复均正确标注「发言者：小王 / 小李」
4. 侧栏最后消息预览实时更新（「刚刚」）

结论：**双向实时可见，消息归属正确，共享房间可用。**

## 过程中发现并修复的 2 个真 bug

1. **消息重复**（`apps/web/src/components/Chat.tsx`）
   乐观消息 + 4s 轮询回读未去重 → 同一轮对话渲染两条。
   修复：轮询合并时移除已被服务端确认的临时副本（`local-*`/`a-*` 同角色同内容），`onDone` 幂等去重。
   回归：重跑确认单组对话。

2. **暗色切换失效**（`apps/web/src/index.css`）
   `@theme` 嵌进 `@media` → Tailwind v4 提升合并到 `:root`，暗色覆盖亮色 → 永久暗色。
   修复：暗色改用普通 `:root` 变量覆盖。
   回归：`07`（亮）/`09`（暗）双主题正确。

## 顺带修复的 auth 缺口

better-auth 默认拒绝跨源（`Invalid origin: localhost:5173`），且 `__Secure-` cookie 在 http 下被浏览器拒收。
修复（`src/auth.ts`）：新增 `BETTER_AUTH_TRUSTED_ORIGINS` 配置；`useSecureCookies` 跟随协议（https 才强制）。
回归：auth 测试 9/9 无破坏。
